# Docupedia

A personal reference repository of Information Security standards — summaries,
clause breakdowns, and study notes.

> **Note:** This repo contains notes and summaries only. Official ISO documents
> are copyrighted and not included. Purchased copies are stored in
> [Google Drive](https://drive.google.com/drive/folders/1CM4qRAFE8jjKRjMPfpenXAb7OvsTWzkl).

## Standards

| Standard | Title | Edition | Status |
|---|---|---|---|
| [ISO/IEC 27001](standards/iso-27001/) | Information Security Management Systems | 2022 + Amd 1:2024 | Clauses + Annex A complete |
| [ISO/IEC 27002](standards/iso-27002/) | Information Security Controls | 2022 | Skeleton |
| [ISO/IEC 27005](standards/iso-27005/) | Information Security Risk Management | 2022 | Skeleton |
| [ISO/IEC 27701](standards/iso-27701/) | Privacy Information Management Systems | 2025 | Skeleton |

## How this is organised

Each standard folder contains:
- **README** — what the standard is, scope, current edition
- **source** — edition metadata and link to licensed documents in Drive
- **clauses/** — one file per clause, plain-English breakdown
- **annex-a/** — for ISO 27001, one file per control theme
- **transitions/** — what changed between editions
