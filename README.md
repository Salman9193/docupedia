# Docupedia

A personal repository of Information Security standards — summaries, clause breakdowns, and study notes.

> **Note:** This repo contains notes and summaries only. Official ISO documents are copyrighted and not included.

## Standards

| Standard | Title | Current Edition | Notes |
|---|---|---|---|
| [ISO/IEC 27001](standards/iso-27001/) | Information Security Management Systems | 2022 + Amd 1:2024 | Certifiable |
| [ISO/IEC 27002](standards/iso-27002/) | Information Security Controls | 2022 | Guidance |
| [ISO/IEC 27005](standards/iso-27005/) | Information Security Risk Management | 2022 | Guidance |
| [ISO/IEC 27701](standards/iso-27701/) | Privacy Information Management Systems | 2025 | Certifiable (standalone) |

## Structure

```
standards/
  iso-{number}/
    README.md        # what the standard is, scope, why it matters
    source.md        # edition, dates, ISO catalogue link
    clauses/         # per-clause notes
    ...
```
