# ISO/IEC 27001 — Information Security Management Systems

## What it is
The certifiable standard for establishing, implementing, maintaining and continually
improving an Information Security Management System (ISMS). Specifies *requirements*,
not a list of controls — the controls live in Annex A (drawn from ISO/IEC 27002).

## Scope
Any organisation, any size, any sector.

## Current edition
- **ISO/IEC 27001:2022** — third edition, published October 2022
- **Amd 1:2024** — adds climate change as a potential context issue (Clause 4.1) and
  a note that interested parties may have climate-related requirements (Clause 4.2)

## Structure
- **Clauses 4–10** — management system requirements (mandatory)
- **Annex A** — 93 controls across 4 themes (organisational, people, physical, technological)

## Key relationships
- 27002 provides implementation detail for Annex A controls
- 27003 gives implementation guidance for this standard
- 27005 covers the risk management process required by Clause 6.1
- 27701 extends (or now stands alongside) for privacy

## Certification
Audited and certified by accredited third-party certification bodies.
