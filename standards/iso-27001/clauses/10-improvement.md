# Clause 10 — Improvement

## 10.1 Continual improvement
Continually improve the suitability, adequacy and effectiveness of the ISMS.

## 10.2 Nonconformity and corrective action
When a nonconformity occurs:
1. React, control, and correct it
2. Evaluate the need for root cause action
3. Implement corrective action if needed
4. Review effectiveness
5. Make changes to ISMS if necessary

Retain documented information as evidence.
