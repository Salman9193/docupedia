# ISO/IEC 27002 — Information Security Controls

## What it is
Guidance standard providing implementation detail for the controls in ISO/IEC 27001
Annex A. Not certifiable on its own — it supports 27001 implementation.

## Current edition
**ISO/IEC 27002:2022** — third edition, published February 2022

## Structure
Same 4-theme structure as 27001 Annex A:
- **A.5** Organisational (37 controls)
- **A.6** People (8 controls)
- **A.7** Physical (14 controls)
- **A.8** Technological (34 controls)

**Total: 93 controls**

Each control entry includes: control statement, purpose, guidance, and attributes
(control type, security property, cybersecurity concept, operational capability, domain).

## ISO catalogue
https://www.iso.org/standard/75652.html

## Relationship to 27001
27001 Annex A lists the controls. 27002 explains how to implement them.
Your SoA (Statement of Applicability) references 27001 Annex A;
your implementation notes should reference 27002 guidance.
